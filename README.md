# 📊 Biblioteca de Vetores em C

Sistema de estatísticas numéricas desenvolvido em linguagem **C**, com foco em praticar **modularização** e manipulação de vetores.

## ✨ Funcionalidades

- Leitura e cadastro de um vetor de números
- Exibição de todos os valores
- Soma dos elementos
- Cálculo da média
- Maior elemento
- Menor elemento
- Dobrar os valores do vetor

## 🧠 Conceitos praticados

- Funções e organização de código
- Vetores
- Laços de repetição
- Estruturas condicionais
- Passagem de vetores para funções

## 🚀 Como executar

O código-fonte está em `main.c`.

**Compilando com GCC:**
```bash
gcc main.c -o biblioteca
./biblioteca
```

**Compilando com CMake:**
```bash
cmake -S . -B build
cmake --build build
```
