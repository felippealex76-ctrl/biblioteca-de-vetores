## Objetivo

Projeto desenvolvido para praticar modularização em C.

## Conceitos utilizados

- Funções
- Vetores
- Laços de repetição
- Condicionais
- Passagem de vetores para funções
- Organização de código

## Funcionalidades

- Leitura de vetor
- Exibição do vetor
- Soma dos elementos
- Maior elemento
- Menor elemento
- Média
- Dobrar os valores do vetor

## Tecnologias

- Linguagem C
- GCC
